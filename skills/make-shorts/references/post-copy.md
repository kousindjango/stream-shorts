# Post copy guide (posts.md)

Write one section per rendered clip in `<workdir>/clips/posts.md`:

```markdown
## c01 — c01.mp4 (47秒)

### YouTube ショート
**タイトル**: ラスボス残り1ミリからの悲劇 #Shorts
**説明**:
残り体力わずか、勝ったと思った瞬間に…
フル配信はこちら → （配信URL）
#ゲーム名 #ゲーム実況 #切り抜き

### X
ラスボス残り1ミリ、勝ちを確信した瞬間に何が起きたか見てほしい
#ゲーム名 #ゲーム実況
```

## Rules
- Base everything on what actually happens in the clip. Do not exaggerate beyond it or invent
  details.
- **YouTube title**: up to 100 characters, but keep the hook in the first ~30 characters (that is all
  the feed shows). Add `#Shorts` at the end. No clickbait that the clip does not pay off.
- **YouTube description**: 1–2 lines of context, a placeholder line for the full stream URL
  (`フル配信はこちら → （配信URL）`) unless the user gave the URL, then 3–5 hashtags.
- **Hashtags**: game title (official spelling), genre or `#ゲーム実況` / `#雑談`, `#切り抜き`, and the
  streamer/channel tag if the user has one. No unrelated trending tags.
- **X post**: X counts each Japanese character as 2 of 280, so stay within ~120 full-width characters
  including hashtags. One or two hashtags. Write it as a natural post, not a title.
- Offer 2 title variants for the top-scored clip if the user wants to A/B test.
- Remind the user (once, in the final report) that free X accounts accept up to 2:20 per video and
  YouTube Shorts up to 3:00.
